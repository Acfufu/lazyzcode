LazyZCode

The discipline layer for ZCode: plan, execute, take evidence, never stop half-done. A plugin plus a lightweight CLI that turns agent claims into verified facts.

Goal loop

Register, plan, execute, verify: a CLI state machine that survives session restarts.

Plan gate

Decision-complete plans only; undecided items rejected. HEAVY plans must pass the reviewer.

Evidence discipline

Real-surface proof bound to a git tree hash. Stale evidence cannot pass the finish gate.

Project memory

init-deep drafts a layered AGENTS.md map of your repo — written only after you approve.

Unattended

Schedule off-peak wake-ups with the engine's own scheduler. Unattended sessions continue existing goals only — never start new ones.

lzy CLI

One command surface for the loop, doctor diagnostics, rate-limit awareness and memory audits. Zero telemetry.
