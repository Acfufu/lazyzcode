# ADR-0032：首版支持按职责与依赖范围复用评审

日期：2026-09-26。状态：设计与整体计划已确认，待实施；资格协议按主计划 §5/§8.1 落实，本轮不执行。

0.4.0 选择支持评审范围资格与对抗验证，而非候选内容任意变化就重跑全部评审。原因是所有契约任务都须独立评审，其重复执行成本需要控制；代价是必须验证依赖边界，防止遗漏影响而错误放行。只有经验证的依赖范围能证明变化不影响该评审职责时才可复用，依赖不明确则重评。

保留原始评审事实，每次沿用另记针对当前候选的适用性判断，不改写旧记录冒充新执行。检查回执沿用 ADR-0025 的机制，不另建证据权威；评审适用性与阻塞发现关闭是不同判断，复用不能替代 ADR-0031 要求的独立复核。能力与错误复用反例必须在本版验证，不以模型一句“应该无关”授予资格。
