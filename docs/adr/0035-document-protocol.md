# ADR-0035：节点间通信=文书协议终局（2026-10-01）

lzy 的跨节点（跨会话/跨工人/评审者与实现者）协作只经**带状态机的语义文书**：计划文件（含换路注记）、发现账本（findings）、评审运行档、交接快照（handoff）、认领（claim）——全部盘上原子写、崩溃可恢复、fail-closed、可被 doctor 巡逻。**自由消息（消息总线/点对点 message 原语/事件流）永不入门**：宿主 SendMessage 类原语是会话内领地（ADR-0036），lzy 不在会话外复刻。拍板理据（2026-10-01 grill「四象限评估与补齐」，对照底稿 `zcode/omo-lzy-compare-report/report.html` 表 6）：①审计优先根——文件中介是「会话会死、账本不能死」的现行实现，消息通道若绕过盘上账本=纪律层开无账通道；②已录跨会话故障（兄弟会话脏树拦 finish、并行撞槽）全部经串行化/认领/stash 纪律修复，无一需要消息通道；③被否的替代方案「账本化消息原语」会成为 lzy 首个无状态机实体，且与 findings/handoff/计划文档三面职责重叠。与 OmO 的取舍同构（mass-ulw 明文「dag 节点不对话，来回辩论换 Team Mode」），媒介不同：它家活邮箱，本仓落账文书——对话能力的落地形态是发现账本上的**异议原语**（open→contested 边，决策 #44），非自由对话。此为终局设计宣言：后续任何「给 lzy 加消息层」的提案须先推翻本 ADR。
